# v1.2.0 — 2026-11-09

- Уточнены параметры сборки MNN для Android по актуальной официальной документации: добавлен `MNN_BUILD_OPENCV=ON`; сохранены Diffusion, LLM tokenizer, OpenCL, low-memory и `SEP_BUILD=OFF`.
- Сборка теперь требует появления исполняемого `diffusion_demo`.
- Упаковщик проверяет ELF-архитектуру каждой библиотеки через `readelf` и отклоняет не-AArch64 файлы.
- Манифест включает ревизию MNN, ABI, путь demo и SHA-256 библиотек.
- Генерация в приложении остаётся выключенной: JNI API и инференс ещё не интегрированы/проверены.
