Сюда помещаются только библиотеки MNN, собранные из одной и той же ревизии исходников
для Android ABI arm64-v8a. Не копируйте сюда случайные .so из разных релизов.

Для MNN-Diffusion потребуются как минимум библиотеки, реально полученные выбранной
конфигурацией сборки MNN (набор зависит от MNN_SEP_BUILD и состава целей).
Пока здесь намеренно нет бинарных библиотек: JNI приложения остаётся диагностическим,
а генерация отключена.
