

## Этап 3 — печать, мокапы и локальная коллекция (v0.3)
- `PosterPdfExporter`: экспорт одностраничного PDF формата A3 portrait из bitmap 1403×1984 px.
- `InteriorMockupRenderer`: композитинг плаката в заданную область фотографии интерьера; координаты рамки задаются пропорционально шаблону.
- `PosterHistoryStore`: локальное хранение PNG в приватном каталоге приложения, список и удаление работ.
- Добавлен enum трёх типов интерьера: кабинет, гостиная, прихожая/лофт.

Ограничения:
- Для мокапов нужны три подготовленные фотографии интерьеров с размеченными координатами рамок; сами фотографии в архив не включены.
- Экспортёр PDF и рендерер мокапов добавлены как отдельные классы, но пока не подключены к кнопкам UI.
- PDF задаёт страницу A3 в пунктах PDF и размещает bitmap целиком; проверка физического размера/120 DPI должна быть выполнена тестовой печатью.
- Генерация по-прежнему заблокирована до подключения реального MNN-Diffusion runtime и модельного пакета. Документация MNN описывает SD 1.5 demo, OpenCL backend и структуру файлов модели; это ещё не доказывает производительность на Honor 20. См. https://github.com/alibaba/MNN/blob/master/transformers/diffusion/README.md.


### JNI diagnostics (v0.8)

`MnnNativeBridge` сообщает, загрузилась ли библиотека `libagitplakat_native.so`. Сообщение `JNI_OK` означает только, что диагностическая библиотека доступна. Оно не подтверждает наличие MNN, OpenCL, весов модели или возможности inference.
